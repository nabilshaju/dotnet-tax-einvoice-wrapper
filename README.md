# dotnet-tax-einvoice-wrapper
-Overview: A library designed to transform standard Sales/Invoice data into a regulatory-compliant XML/JSON format for E-Invoicing.

-Key Features:

      -Validation Engine: Checking for required tax fields before transmission.
      
      -Secure Transmission: Using HttpClient with SSL/TLS and API keys.
      
      -Logging & Audit: Tracking invoice status (Success/Failure/Pending).
